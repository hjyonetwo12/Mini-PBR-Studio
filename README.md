# Mini-PBR-first-project
 主要通过LearnOpenGL教程模仿学习编写的新手代码
 资料整理方面：信息来源主要是C++官方文档，C++菜鸟教程，GLSLAPI官方指南
整理和问题咨询主要通过基础的对话AI来完成，包括代码基础骨架，还有部分语法方面的问题大部分官方文档里看不懂的也是咨询对话AI来完成，总体上算是不错的尝试
这三天经历了从C++完全看不懂到从C++菜鸟教程建立C++基础知识框架，再到借助AI生成代码骨架和向AI索要基本的推荐学习网址与官方文档网站，再到AI帮助分析代码错误和点对点解决问题
可见AI是极其强大的高效工具，极其适合新手的使用，甚至目前的对话AI是完全免费的，不过AI幻觉确实是一个需要严谨对待的问题，这也是在不断学习的过程中需要攻克的难点之一
最后是新手的感慨：图形学入门给我难哭了！！！
